The decisionsbehind it.

Choosing the model

Gemini, on purpose

OpenAI had no free tier and wanted a card. Anthropic's API bills separately from a chat plan. Gemini's free tier let me build and test all five stages without paying.

Keeping stages honest

Pydantic between every step

LLM output is unpredictable. Validating each stage's JSON before passing it on means one bad response fails loudly instead of quietly breaking everything after it.

From team to solo

Shipped it alone

It started as a hackathon build under the team name Chaos2Commit. When the team split, I kept going and took it from backend to a live deploy.
